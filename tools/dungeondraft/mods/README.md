# Project-controlled Dungeondraft Mods

This directory is intended to be selected as the Dungeondraft mods folder for the integration spike.

Run `..\\scripts\\Install-BridgeMod.ps1` from PowerShell to prepare `dungeondraft-mcp-bridge/` from the pinned submodule. The generated copy is ignored because it is reproducible and the submodule remains the dependency source.

Selecting this directory in Dungeondraft is a manual application setting. The repository setup does not change Dungeondraft user configuration automatically.
